# 3D model credits (Booking Desk nested-stays model)

The house geometry is drawn in code from plan.ts. Every texture, the sky and the furniture models are free CC0 assets (Poly Haven, ambientCG), copied from the Listing Studio asset set and listed in the page under "3D model sources". No paid assets, no API keys.
